# BLUE/GREEN FOR DEPLOYMENT AND DISASTER RECOVERY

## What?
This repo is meant as a place to visualize some ideas on having a blue/green deployment strategy do double duty as a disaster recovery tool from a high level perspective.  This repo is a work in progress. 

## Why?
The biggest blocker in implementing blue/green capability is cloud cost.  I wanted to develop a set of variations on the "blue/green deployment strategy as disaster recovery strategy" concept that represent different cloud cost tiers and a breakdown of the pros and cons of each one.

## Where?
AWS is the main provider here but these ideas can be easily ported to another provider's ecosystem.

## How?
Each branch here represents a different loosely defined cloud costs tier ranging from 'The Heftiest' to 'Hefty' to 'Cheap Ass' to 'No Cost' and various tiers inbetween.
